# Modelo operacional
| Elemento | Responsabilidade |
|---|---|
| Notion | Conhecimento, estratégia, Foundation Docs, PRDs, ADRs e editorial |
| Sas-Executar/Copiloto | Schema canônico e espelho da planilha |
| executar-23/Copiloto-ops | Alvo: operação, backlog e instruções |
| Sas-Executar/executar-Blog | Código e deploy do produto; referência técnica |
| Sas-Executar/OPS-COPILOTO | Fora do escopo atual; nenhuma nova alteração |

| Objeto | Uso |
|---|---|
| Project | Visão global, board, roadmap e status |
| Epic | Resultado composto por entregas |
| Issue | Entrega verificável |
| Sub-issue | Trabalho filho com vínculo confirmado |
| Checklist | Passos internos de uma entrega |
| Milestone | Meta/release temporal, distinta de Epic |
| Gate | Controle de governança com ID canônico |
| Label | Classificação somente no vocabulário aprovado |
| Issue Type | Natureza do trabalho, distinta de label |
| Fields | Dados estruturados quando disponíveis |
| Dependency | Bloqueio real, verificado |
| PR/commit | Implementação rastreável |

Foundation, Platform, Blog, Agent, Editorial, Deploy e Operations são propostas de agrupamento, não Epics criados ou IDs canônicos confirmados.
